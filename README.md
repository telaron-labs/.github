# telaron-labs

This repository powers the **[telaron-labs](https://github.com/telaron-labs)**
organisation profile — the landing page you see on the org's Overview tab lives
in [`profile/README.md`](profile/README.md).

It also holds the parent-org **brand** — the *Limb Light* mark, wordmark,
avatars, and the mission patch — under [`brand/`](brand/), so anything carrying
the Telaron Labs identity starts from a single source of truth.

> Shared CI plumbing (reusable workflows, composite actions) lives in a separate
> internal repository, not here.
